API Docs

CanvasManager

Manages canvas lifecycle operations, handles device pixel ratio (DPR) scaling for high-density Retina displays, and tracks resize observations.

constructor(container: HTMLElement, height: number, widthOption: number | 'auto', onResize: (payload: ICanvasResizePayload) => void)

Initializes the canvas element, attaches it to the parent DOM element, configures the 2D rendering context, and establishes layout listeners.

            const canvasMgr = new CanvasManager(document.getElementById('chart-box'), 400, 'auto', (payload) => console.log(payload));
resize(widthOption: number | 'auto', height: number, margin: Margin): ICanvasResizePayload

Calculates physical dimensions against the device pixel ratio to scale coordinate grids cleanly without text blurring. Returns the modern sizing payload parameters.

setupResizeObserver(widthOption: number | 'auto', height: number): void

Attaches a performance-optimized native browser ResizeObserver wrapper loop to track container bounding box alterations seamlessly.

getMouseCoordinates(event: MouseEvent): Point

Transforms raw client pointer viewport positioning tokens relative to the strict structural borders of the underlying active canvas node wrapper.

destroy(): void

Disconnects observers and detaches element bindings from the DOM tree nodes to guarantee leak-free garbage collection passes.

Chart<T>

The abstract orchestration base framework layer providing fundamental shared configurations, states, and global theme mutations.

constructor(containerId: string, data: T[], options?: IChartOptions)

Validates target references, assigns tracking settings options, merges user configs, and constructs base canvas infrastructure layers.

handleResize(skipRendering?: boolean): void

Re-evaluates dimension configurations whenever wrapper nodes pivot, realigning spatial metrics before re-dispatching graphic draw calls.

clear(): void

Wipes the 2D canvas context viewport blank across current frame parameters in preparation for subsequent animation ticks.

updateData(newData: T[]): void

Ingests a fresh data package matrix dynamically, shifting state stores and pushing an instant visual redraw process pipeline.

            myChart.updateData([{ label: 'Q3', value: 450 }]);
setTheme(newTheme: 'light' | 'dark'): void

Swaps the internal design tokens container palette structural values cleanly between 'light' and 'dark' states, forcing instant re-renders.

            myChart.setTheme('dark');
destroy(): void

Standard disposal engine teardown hook mapping clean operations down through components, managers, and downstream event emitters.

abstract render(): void

Abstract execution strategy target framework footprint. Must be overridden explicitly inside concrete rendering pipeline extensions.

CartesianChart

Abstract extension structure for grid-based charting engines (Bar, Line). Houses interaction logic, crosshairs, grids, and axes components.

setupCartesianInteractions(): void

Attaches high-performance mouse event tracking arrays across coordinate matrices, resolving active interactive hit zones on hover vectors.

final render(): void

Final framework template method. Locks the lifecycle sequence down: clears, shifts matrices, injects grids/axes, and renders graphics.

abstract prepareRenderState(): void

Abstract hook forcing extensions to pre-calculate geometric boundaries, value distributions, and max thresholds before pixel plotting begins.

getProcessedData(): IDataPoint[]

Returns data arrays ready for consumption, running optimizations or downsampling operations where structural filters specify.

abstract drawChartGraphics(renderData: IDataPoint[], maxValue: number): void

Abstract operational drawing hook where concrete implementations parse coordinates to draw bars, paths, dots, or area nodes.

abstract checkHitZone(mouseX: number, mouseY: number): number

Abstract geometric layout validator evaluating structural boundaries to detect if pointer coordinates collide with item geometries.

abstract handleTooltipShow(hitIndex: number, mouseCoords: Point): void

Abstract utility bridge translating target indexes into structured string payloads mapped cleanly directly into HTML floating modules.

PolarChart

Abstract base extension layer tailored specifically around angular radial layouts, concentric boundaries, and spatial math calculations.

setupPolarInteractions(): void

Listens to pointer movement vectors, projecting Cartesian offsets into circular trigonometric arcs to resolve angular slices on hover.

getPolarMetrics(): { centerX: number; centerY: number; outerRadius: number }

Computes structural center positions along with outer limits based on padding configurations and size parameters.

validateRadiusDistance(distance: number, outerRadius: number): boolean

Overridable validation criteria checking if interactive rays lie inside valid radial bounds. Useful for deadzone checking.

BarChart

Concrete Cartesian implementation plotting category units horizontally along bounded geometric pixel columns.

prepareRenderState(): void

Calculates categorical scale steps and bounds, storing rectangular bounding boxes inside the local tracking interaction cache array.

drawChartGraphics(renderData: IDataPoint[], maxValue: number): void

Iterates structural data blocks, drawing standard paths using 2D rendering lines, applying active themes or hovered lighting parameters.

LineChart

Concrete Cartesian implementation plotting series nodes linked continuously through multi-point bezier or linear path tracks.

getProcessedData(): IDataPoint[]

Intercepts pipeline streams, evaluating node weights against thresholds to automatically trigger localized data downsampling loops.

downsampleData(rawSrc: IDataPoint[], targetBucketSize: number): IDataPoint[]

Optimizes frame pipelines by mapping large point datasets into simplified structural approximations using bucket sampling algorithms.

PieChart & DonutChart

Concrete radial engines that translate datasets into percentage allocations mapped across angular slice arcs.

validateRadiusDistance(distance: number, outerRadius: number): boolean

(DonutChart Override) Filters inner radius criteria to suppress mouse interactions when pointers hover within the deadzone cutout circle.

Timeline

Isolated ticker engine running precision interpolation alphas synced against native high-frequency browser animation clock updates.

loop(timestamp: number): void

Calculates delta durations across framework frames, updating weights between 0.0 and 1.0 before dispatching state synchronization triggers.

play() / pause() / reset(): void

Controls operational states, locking loops, updating flags, or resetting active frame markers to initial states.

            timeline.play();

RaceChart

Real-time data visualization structure rendering racing data animations over time using interpolated frame vectors.

processAnimationFrame(currentFrame: IRaceTimelineFrame, nextFrame: IRaceTimelineFrame | null, alpha: number): void

Calculates the tween states between active milestones, mapping changing values, changing color tokens, and vertical rank transitions.

startRace() / pauseRace() / resetRace(): void

Passthrough lifecycle drivers triggering internal timeline clock behaviors to manage state tracking variables cleanly.

Axis

Renders tick rules, boundary baselines, and numeric descriptions to structural coordinate systems.

drawY(ctx: CanvasRenderingContext2D, margin: Margin, chartHeight: number, maxValue: number, theme: IChartTheme): void

Calculates data steps, rendering precise vertical text markers and scale indicator values along layout boundaries.

drawXBaseline(ctx: CanvasRenderingContext2D, margin: Margin, chartWidth: number, chartHeight: number, theme: IChartTheme): void

Emits a straight horizontal base structural rule matching the active color values defined within the theme layout matrices.

Grid

Draws dashed background reference lines across Cartesian canvas systems.

draw(ctx: CanvasRenderingContext2D, margin: Margin, chartWidth: number, chartHeight: number, maxValue: number, theme: IChartTheme): void

Computes coordinate distributions, projecting uniform dashed vector lines horizontally across background spaces.

Tooltip

DOM-isolated floating container tracking mouse vectors to render detailed structural item descriptions.

show(mousePos: Point, data: ITooltipData, theme: IChartTheme): void

Calculates alignment dimensions against viewport limits, transforming the tracking card container position using CSS transforms.

            tooltip.show({ x: 120, y: 200 }, { title: 'Sales', value: 12400, color: '#2563eb' }, theme);
hide(): void

Swaps element opacity configurations or display states instantly to hide the tooltips from view cleanly.
